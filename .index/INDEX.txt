com.patchnote.visualswap.SwapWindow  [Updated: 2026-06-29]
  Pure, Minecraft-free state machine for the swap-hit glyph; src/main (common). WINDOW_TICKS=2 (possible window; grounded: attribute swap is same-tick — 1-tick detectEquipmentUpdates lag + 1-tick client end-of-tick observation), FLASH_TICKS=5 (attacked variant duration ~250ms), NO_TICK sentinel. Fields: lastSwapTick, flashUntilTick, possibleLastTick.
  onSwap(tick) arm possible window; clear() reset all; onClick(tick) starts flash (flashUntilTick=tick+FLASH_TICKS) IFF possible(tick) OR possibleLastTick — i.e. same-tick swap+attack (real exploit; client calls onSwap before onClick) OR clicked one tick after; possible(tick)=set && 0<=tick-lastSwapTick<WINDOW_TICKS; attacked(tick)=tick<flashUntilTick; visible(tick)=possible||attacked; endTick(tick) sets possibleLastTick=possible(tick) (call once at tick end). Clock = player.tickCount.

com.patchnote.visualswap.client.VisualSwapClient  [Updated: 2026-06-30]
  ClientModInitializer; the mod's only entrypoint ("client" in fabric.mod.json); src/client. onInitializeClient: VisualSwapParticles.registerTypes()+registerFactories(); attach glyph HUD after HOTBAR; ClientTickEvents.END_CLIENT_TICK + AttackEntityCallback + UseEntityCallback (both -> onInteractEntity via lambda). Detection = swap window (SwapWindow), no attribute math; clock=player.tickCount.
  STATE: all per-tick mutable state lives in a nested `private static final class State` snapshot (one field `state` = last completed tick's snapshot). Fields: tick, primed, mainHand(ItemStack), selectedSlot, attackDown, useDown, swinging, swingTime, attacked, swapFromSlot/swapToSlot, highlightFromSlot/highlightToSlot (latched, =NO_SLOT default). Built each tick via static State.capture(previous,player,client): inherits the latched swap/highlight slots from previous (copy-ctor State(previous)) then reads all raw observations (tick=tickCount, primed=true, selectedSlot, mainHand=getMainHandItem().copy(), attackDown/useDown=key isDown, swinging/swingTime). Caller then fills derived fields (swap slots on swap, attacked, highlight slots on attacked-edge), compares against `previous`, then `state=current`. (Future plan: detect consecutive attribute swaps by comparing snapshots.) reset() = `state=new State()` + swapWindow.clear() when player==null.
  onEndClientTick: ANY main-hand change (!ItemStack.isSameItem(previous.mainHand,current.mainHand)) opens window via swapWindow.onSwap(tick) — INCLUDING to/from empty (covers spear<->empty lunge swap) and different item types; isSameItem ignores count/durability ticks; on a swap, records current.swapFromSlot=previous.selectedSlot, swapToSlot=current.selectedSlot. State.primed (false on the EMPTY sentinel) skips the first post-spawn tick (no false swap). NO clear-on-empty. CLICK = swingStarted OR attack/use key rising edge (vs previous.*) -> swapWindow.onClick(tick) (flashes attacked iff possible this OR last tick). swingStarted = current.swinging && (!previous.swinging || current.swingTime<previous.swingTime): the spear jab takes a special path (startAttack->piercingAttack, NO AttackEntityCallback) and is a fast sub-tick click the key edge misses, so detect the swing it always triggers (LivingEntity.swinging/swingTime public). glyph.update(visible,attacked); swapWindow.endTick(tick) before storing state.
  HOTBAR HIGHLIGHT: on the rising edge of attacked (current.attacked && !previous.attacked) freezes current.highlightFromSlot/highlightToSlot = current.swapFromSlot/swapToSlot, then SwapHotbarHighlight.INSTANCE.update(current.attacked, ...) each tick so the gray boxes show only while the flash runs (HudHotbarHighlightMixin renders them).
  onInteractEntity(player,entity) [attack OR use on entity]: guard player==mc.player; live switchedThisTick (!isSameItem vs this.state.mainHand = last tick's snapshot) OR swapWindow.possible(tickCount) -> spawnParticles burst on target, returns PASS (checked live since callbacks run in handleKeybinds before END_CLIENT_TICK). spawnParticles: SWAP_ATTACKED gaussian cloud at target.getY(0.5), count 18, spread 0.45. NOTE: a spear jab into air has no entity target -> glyph only (no particles).
