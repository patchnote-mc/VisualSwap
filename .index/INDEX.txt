com.patchnote.visualswap.SwapWindow  [Updated: 2026-06-29]
  Pure, Minecraft-free state machine for the swap-hit glyph; src/main (common). WINDOW_TICKS=2 (possible window; grounded: attribute swap is same-tick — 1-tick detectEquipmentUpdates lag + 1-tick client end-of-tick observation), FLASH_TICKS=5 (attacked variant duration ~250ms), NO_TICK sentinel. Fields: lastSwapTick, flashUntilTick, possibleLastTick.
  onSwap(tick) arm possible window; clear() reset all; onClick(tick) starts flash (flashUntilTick=tick+FLASH_TICKS) IFF possible(tick) OR possibleLastTick — i.e. same-tick swap+attack (real exploit; client calls onSwap before onClick) OR clicked one tick after; possible(tick)=set && 0<=tick-lastSwapTick<WINDOW_TICKS; attacked(tick)=tick<flashUntilTick; visible(tick)=possible||attacked; endTick(tick) sets possibleLastTick=possible(tick) (call once at tick end). Clock = player.tickCount.

com.patchnote.visualswap.client.VisualSwapClient  [Updated: 2026-06-29]
  ClientModInitializer; the mod's only entrypoint ("client" in fabric.mod.json); src/client. onInitializeClient: VisualSwapParticles.registerTypes()+registerFactories(); attach glyph HUD after HOTBAR; ClientTickEvents.END_CLIENT_TICK + AttackEntityCallback + UseEntityCallback (both -> onInteractEntity via lambda). Detection = swap window (SwapWindow), no attribute math, no mixins; clock=player.tickCount.
  onEndClientTick: ANY main-hand change (!ItemStack.isSameItem vs previousMainHand) opens window via swapWindow.onSwap(tick) — INCLUDING to/from empty (covers spear<->empty lunge swap) and different item types; isSameItem ignores count/durability ticks. `primed` flag skips the first post-spawn tick (no false swap). NO clear-on-empty. CLICK = swingStarted OR attack/use key rising edge -> swapWindow.onClick(tick) (flashes attacked iff possible this OR last tick). swingStarted = player.swinging && (!wasSwinging || swingTime<previousSwingTime): the spear jab takes a special path (startAttack->piercingAttack, NO AttackEntityCallback) and is a fast sub-tick click the key edge misses, so detect the swing it always triggers (LivingEntity.swinging/swingTime public). glyph.update(visible,attacked); swapWindow.endTick(tick); reset() all when player==null. Tracks previousAttackDown/UseDown + wasSwinging/previousSwingTime.
  onInteractEntity(player,entity) [attack OR use on entity]: guard player==mc.player; live switchedThisTick (!isSameItem) OR swapWindow.possible(tickCount) -> spawnParticles burst on target, returns PASS (checked live since callbacks run in handleKeybinds before END_CLIENT_TICK). spawnParticles: SWAP_ATTACKED gaussian cloud at target.getY(0.5), count 18, spread 0.45. NOTE: a spear jab into air has no entity target -> glyph only (no particles).
